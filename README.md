## 🎮 How to Play

- The game will show you an image of a Titan.
- You must click on the correct human character who possesses the Titan.
- Score increases with each correct answer, and high scores are tracked.
- Wrong answers will dim the image and reduce your score.

## ✨ Features

- Interactive UI with modern styling and animations.
- Image-based multiple choice interface.
- Live score and high score tracking.
- Responsive layout.
- Smooth transitions and feedback for correct/wrong answers.
